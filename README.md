# Clinic / Salon / Gym Demo Website

Demo website by [Raymelz](https://raymelz.com/) for appointment-based businesses. One site, three complete looks:

| Version | Link to share |
|---|---|
| Clinic (teal, medical) | `index.html?type=clinic` |
| Salon (rose, elegant) | `index.html?type=salon` |
| Gym (dark, neon) | `index.html?type=gym` |

The bar at the top lets visitors switch between the three versions.

## Features
- A 4-step online booking system: choose a service, then a doctor, stylist or trainer, then a date and time slot, then enter details. It ends with a confirmation screen, an "Add to Calendar" (.ics) download and a WhatsApp confirmation link.
- Each business has its own closed days, opening hours and already-booked slots.
- Services, team, packages or memberships, a scrolling gallery, reviews, FAQs, a map and a WhatsApp button.

## Editing content
All text, prices, photos and team members for each version are in `js/data.js`.

## Host on GitHub Pages
1. Create an empty repo, for example `clinic-demo`.
2. Push the contents of this folder, so that `index.html` sits at the repo root.
3. Go to **Settings → Pages → Deploy from a branch → main / (root) → Save**.
